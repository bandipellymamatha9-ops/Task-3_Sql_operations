# Employee Database SQL Project

## About This Project
This is a beginner-friendly SQL project. It shows how to create an employee database and work with employee, department, and salary information.

## Database Name
`employee_db`

## Tables in This Project
1. **employees** - Stores employee details such as ID, name, gender, age, department ID, and city.
2. **departments** - Stores department ID, department name, and location.
3. **salaries** - Stores salary ID, employee ID, and salary.

## What I Did
- Created the employee database.
- Created three tables.
- Added sample records to the tables.
- Used `WHERE` to find records that match a condition.
- Used `ORDER BY` to sort records.
- Used `GROUP BY` with functions such as `COUNT`, `AVG`, and `MAX`.
- Used `INNER JOIN` and `LEFT JOIN` to combine information from tables.
- Used `UPDATE` to change existing records.
- Used `DELETE` to remove a record.
